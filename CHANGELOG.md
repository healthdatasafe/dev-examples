## 1.0.0 — 2026-11-17

### Added
- **`weight-quickstart`**: the smallest Health Data Safe web app (plain JavaScript, Vite, `hds-lib`). Sign-in button
  with a commented demo/production switch, a form that stores a weight (`body-weight`, `mass/kg`), and the list of
  stored weights. Permissions built from item keys with `forItemKeys` (`contribute`). Runs on `http://localhost`,
  no HTTPS setup.
- Repository layout: one self-contained folder per example, root lint (neostandard, semicolons), BSD-3-Clause.
